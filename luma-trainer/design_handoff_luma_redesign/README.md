# Handoff: Редизайн Luma — «панель в рамке»

## Overview
Полный редизайн UI тренажёра английского Luma (Next.js, `luma-trainer/`): все разделы (Сегодня, Уроки, Фразы, Правила, Прогресс, Настройки) плюс экран сессии учёбы (карточка). Стиль: белая скруглённая рамка на насыщенном цветном фоне, внутри — цветная панель с радиальным градиентом, огромная строчная типографика Baloo 2, «стеклянные» пилюли, белые кнопки-пилюли, переключатель цветовой темы (4 акцента). Тёмная тема удаляется.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы в HTML** (прототипы), не production-код. Задача — **воссоздать этот дизайн в существующем стеке проекта** (Next.js App Router + Tailwind CSS v4 + существующие компоненты в `components/`), используя его паттерны: секции в `components/sections/*`, сессия в `components/study/StudySession.tsx`, токены в `app/globals.css`. Вся текущая логика (FSRS, API `lib/api`, подсказка `lib/hint.ts`, hotkeys) сохраняется без изменений — меняется только представление.

## Fidelity
**High-fidelity.** Цвета, шрифты, радиусы, отступы и состояния — финальные, воспроизводить точно.

## Общий каркас (все экраны)
- `body`: фон `--outer` (см. палитры), padding `clamp(10px, 2.5vw, 32px)`.
- Белая рамка: `background:#fff; border-radius:clamp(26px,4vw,52px); padding:clamp(10px,1.6vw,22px); box-shadow:0 30px 80px rgba(0,0,0,0.25)`.
- Внутренняя панель: фон `--panel` (радиальный градиент), `border-radius:clamp(18px,3vw,38px); padding:clamp(16px,3vw,40px); min-height:calc(100vh - clamp(60px,12vw,120px))`. Переход фона `0.5s ease` при смене темы.
- Шрифт: **"Baloo 2"** (Google Fonts, 400–800), везде, включая инпуты и кнопки (`font-family:inherit`).
- Логотип: `luma` + точка цветом `rgba(255,255,255,0.55)`, weight 800.

## Цветовые темы (палитры)
Выбор темы — в Настройках → «Оформление»; сохранять (сейчас в настройках приложения). Тема = 4 значения:

| Тема | outer | panel (radial-gradient 120% 150% at 28% 18%) | accent | dot |
|---|---|---|---|---|
| blue | #0a3a9e | #3572e8 → #1c55c9 48% → #0c3da5 | #1150c8 | #2f6fe0 |
| green | #0b5c31 | #2fae63 → #1a8a4c 48% → #0d5f33 | #0f7a41 | #27a35c |
| purple | #3c1878 | #8a55e0 → #6a34c4 48% → #4b1f96 | #6a2fc9 | #7e46d8 |
| red | #7c1a1a | #e05555 → #c03434 48% → #8f1f1f | #c23434 | #d64c4c |

`accent` используется для: текста на белых кнопках, заливки прогресс-баров, активных тумблеров, ссылок «Учить урок».

## Базовые компоненты
- **Белая кнопка (primary)**: `background:#fff; color:accent; border-radius:999px; font-weight:800; box-shadow:0 6–10px 18–26px rgba(0,0,0,0.18–0.22); min-height:44–58px; padding:0 20–42px`. Hover: `translateY(-1/-2px)`.
- **Стеклянная пилюля (secondary)**: `background:rgba(255,255,255,0.14); border:1px solid rgba(255,255,255,0.25); backdrop-filter:blur(8px); color:#fff; border-radius:999px; font-weight:700`. Hover: фон `0.26`.
- **Белая карточка контента**: `background:#fff; border-radius:20–24px; padding:14–20px; box-shadow:0 8–10px 22–26px rgba(0,0,0,0.12–0.14)`. Текст в карточках: заголовок `#23304d` (800), вторичный `#7a86a3`, третичный `#a8b1c9`, тело `#3b4763`.
- **Чипы в карточках**: `border-radius:999px; font-size:12px; font-weight:700`; нейтральный `#eef1f8`/`#7a86a3`, выучено `#e2f6ec`/`#23a66f`, акцентный `color-mix(accent 12%, #fff)`/accent, опасный `#fdf3f3`/`#d64c4c`.
- **Прогресс-бар**: трек `#e8ecf7` (в стекле — `rgba(255,255,255,0.x)`), заливка accent (выученные — `#23a66f`), высота 9–10px, radius 999px, `transition:width 0.5s cubic-bezier(0.2,0.8,0.2,1)`.
- **Точка сложности**: 12px круг; d≤3 `#23a66f`, ≤5 `#9acd32`, ≤7 `#f5972b`, иначе `#d64c4c`.
- **Тумблер**: пилюля; Вкл = accent/белый текст, Выкл = `#eef1f8`/`#7a86a3`, надпись «Вкл/Выкл».
- **Переключатель темы**: белые/светлые круги 40–42px с цветным кружком 16px (`dot`), активный — кольцо `3px solid` (белое на панели, accent на белой карточке).

## Навигация
Верх панели: логотип слева, по центру пилюли разделов (активная — белая с accent-текстом, остальные — стеклянные), справа кнопка «▶ сессия» (белая). На мобильном — flex-wrap.

## Interactions & Behavior
- Смена раздела: fade-up контента (opacity 0→1, translateY 18px→0, 0.4s cubic-bezier(0.2,0.8,0.2,1)).
- Hover белых кнопок — подъём 1–2px; стеклянных — фон до 0.26; иконок-кругов — без движения.
- Звезда избранного: `active { transform:scale(1.3) }` 0.15s.
- При выключенных анимациях (настройка) все transition/animation отключать.
- Responsive: всё на flex-wrap + clamp(); отдельных брейкпоинтов почти нет. Мин. высота тач-целей 44px (мелкие иконки ✎/🗑 32–36px допустимы в плотных списках).
