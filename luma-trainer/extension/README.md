# Luma — расширение для субтитров (MV3)

Сохраняет фразы из субтитров фильмов/сериалов прямо в Luma.

## Установка

1. Запусти Luma (`npm run dev -- -p 3400`).
2. Chrome/Edge → `chrome://extensions` → включи «Режим разработчика».
3. «Загрузить распакованное расширение» → выбери эту папку `extension/`.
4. Открой настройки расширения (ссылка в попапе) и укажи адрес Luma, если он не `http://localhost:3400`.

## Как пользоваться

- На странице с видео открой попап расширения — последняя реплика субтитров подставится автоматически.
- Кнопки «Из субтитров» / «Из выделения» — заполнить поле текущим субтитром или выделенным текстом.
- Выбери урок (или создай «Из субтитров») и нажми «Сохранить фразу». Перевод догрузится в Luma в фоне.
- «Снимок области» — делает скриншот вкладки как визуальную подсказку для ручного ввода (OCR-fallback).

## Поддержка

YouTube · Netflix · HTML5-`<track>` дорожки · произвольные `caption`/`subtitle` DOM · ручное выделение · снимок вкладки. Сохраняются URL источника и временная метка.

Расширение **не** обходит DRM и **не** скачивает защищённое видео — читается только видимый текст.
