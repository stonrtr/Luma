# Luma — тренажёр английского

Персональный тренажёр английских слов, фраз и грамматических правил с интервальным повторением (FSRS-подобная модель). Ты добавляешь только свой материал; приложение само решает, что и когда повторять.

Стек: **Next.js 16 (App Router) · TypeScript · Prisma + SQLite · Tailwind v4**. Порт **3400**.

## Возможности

- **Сегодня** — очередь повторения с приоритетом (просроченные → низкий прогресс → «не вспомнил» → давно не повторялись → новые). Пусто, когда повторять нечего.
- **Карточка** — 3D-переворот, подсказка по одной букве, озвучка, оценки «Не вспомнил / С трудом / Легко», управление с клавиатуры (`Space`, `←↓→`, `↑` подсказка, `Shift` озвучка, `Esc`).
- **Мои уроки** — темы → уроки → фразы, счётчики, сортировки, «Учить урок», архив, импорт, пересборка переводов.
- **Мои фразы / Избранное** — единая коллекция, сортировки, звёздочка, редактирование, удаление с подтверждением.
- **Правила** — грамматика генерируется LLM: объяснение, формула, примеры, маркеры, ошибки, сравнение и интерактивные упражнения с гибкой проверкой ответа.
- **Прогресс** — метрики, распределение по прогрессу, активность за 7 дней.
- **Настройки** — лимиты, критерии «выучено» (с пересчётом), голос/скорость/автоозвучка, тема, анимации.
- **Импорт** — массово, без потери строк при ошибке переводчика; переводы догружаются в фоне.
- **PWA** — устанавливается на телефон, работает офлайн-оболочка.
- **Расширение браузера** (MV3) — сохраняет фразы из субтитров (см. `extension/`).

## Запуск

```bash
npm install
npx prisma db push        # создать схему БД (prisma/luma.db)
npx tsx prisma/seed.ts     # демо-данные (по желанию)
npm run dev -- -p 3400
```

Открыть http://localhost:3400.

### Переменные окружения (`.env`, только на сервере — в клиент не попадают)

```
DATABASE_URL="file:/абсолютный/путь/prisma/luma.db"
GEMINI_API_KEY="…"          # основной переводчик/генератор
GEMINI_MODEL="gemini-2.5-flash"   # у free-tier gemini-2.5-pro квота = 0
ANTHROPIC_API_KEY="…"       # резервный провайдер (необязательно)
DEEPGRAM_API_KEY="…"        # серверный TTS (иначе — голос браузера)
```

Каскад перевода: **Gemini (с авто-переключением моделей при 429) → Anthropic → ручной ввод**. Ошибка LLM никогда не блокирует сохранение карточки.

## Проверки

```bash
npm test          # unit-тесты (нормализация, импорт, FSRS, прогресс, подсказка, проверка ответов)
npm run lint
npm run build
```

## Расширение (субтитры)

`chrome://extensions` → «Загрузить распакованное» → папка `extension/`. В настройках расширения указать адрес Luma (по умолчанию `http://localhost:3400`). Работает с YouTube, Netflix, HTML5-плеерами с текстовыми дорожками, произвольными subtitle-DOM, ручным выделением и снимком области как подсказкой. DRM не обходит и защищённое видео не скачивает.
