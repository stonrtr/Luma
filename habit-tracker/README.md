# Направления жизни

Десктопное приложение для управления направлениями жизни. Главный экран отвечает на один вопрос — **что мне нужно сделать сегодня**, вторым слоем показывает, что накатывает до конца недели и как держатся привычки.

Реализовано по ТЗ (`TZ-life-tracker.md`), визуальный референс — прототип `desktop-v2.html`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3700
```

БД (`data.db`, SQLite) создаётся автоматически и наполняется демо-данными (3 направления, цели обоих типов, привычки с историей за 30 дней). Чтобы начать с чистого листа — удали `data.db*` и перезапусти.

Приложение десктопное (min-width 1024px), три зоны: рейка направлений · центр · привычки.

## Модель данных

**Направление → Цель → Задачи + Привычки.** Единого показателя «жизнь = X%» нет — процент имеет смысл только внутри направления.

- **Два типа целей.** *Достижение* (`achievement`) имеет финиш: прогресс растёт к 100% из задач (0.7) и привычек (0.3), цель закрывается. *Поддержание* (`maintenance`) финиша не имеет — показывает удержание привычек за 30 дней.
- **Инбокс.** Задача может быть без цели (`goalId = null`) — попадает в «Сегодня», в проценты не входит.
- **Привычки** трёх расписаний: ежедневно, по дням недели, N раз в неделю.
- Отметки привычек (`HabitEntry`) можно ставить только за прошлое и сегодня — будущие дни на уровне данных запрещены.

Все расчёты собраны в одном месте — [`src/lib/progress.ts`](src/lib/progress.ts) (adherence, прогресс цели/направления, заполненность дня, серии).

## Экран

- **Рейка (слева):** «Сегодня» со счётчиком незакрытых задач, список направлений с процентом и полосой, «+ направление».
- **Центр, режим «Сегодня»:** дата прописью, линия недели (ретроспектива `dayCompletion`), крупный список задач на сегодня + инбокс, полоса переноса просроченных, блок «Осталось на этой неделе» (6 дней вперёд).
- **Центр, режим направления:** цели карточками — процент/удержание, привычки цели с adherence, раскрывающийся блок задач, добавление задач/привычек, «завершить цель».
- **Привычки (справа):** для каждой — окно из 7 дней (3 назад · сегодня · 3 вперёд), доотметка прошлого, будущее только план, серия крупной цифрой.

## Клавиатура

`↑ ↓` — навигация по списку сегодня · `Space` — отметить · `Ctrl/⌘ + N` — новая задача (или кнопка «+ задача») · `1…9` — переключение направлений · `Esc` — закрыть модалку.

> Примечание: `⌘N`/`Ctrl+N` в некоторых браузерах перехватывается системой (новое окно). На этот случай в шапке «Сегодня» есть видимая кнопка **+ задача**.

## Архитектура

Next.js 16 (App Router) · React 19 · better-sqlite3, без внешних UI-библиотек. Данные загружаются снапшотом на сервере, всё редактирование — оптимистично в клиентском сторе ([`src/lib/store.tsx`](src/lib/store.tsx)) с фоновой записью в SQLite через `POST /api/mutate`. Отсюда мгновенный отклик без спиннеров. id — UUID, у записей `updated_at` — схема заложена под будущую синхронизацию.

Порт **3700**.
