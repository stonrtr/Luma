# Handoff: Редизайн Luma — «Bethouse»

## Overview
Полный редизайн UI тренажёра английского Luma по референсу Bethouse: полноэкранный синий градиент без белой рамки, стеклянные панели, белые пилюли, текстовая навигация, одна цветовая тема (синяя), шрифт Onest.

Файлы (открываются в браузере как есть, это же спецификация с живым поведением):
- `Luma (Bethouse).dc.html` — главная: разделы Сегодня / Уроки / Фразы / Правила / Прогресс / Настройки (переключение в шапке; проп `defaultSection`).
- `Карточка (Bethouse).dc.html` — экран сессии: вопрос / ответ / финал (проп `defaultView`), подсказка по буквам, озвучка, оценки, хоткеи (Space, ↑, Shift, ← ↓ →).
- `Все экраны (Bethouse).dc.html` — обзорная панорама всех 9 экранов.

## Токены

### Цвет
- Фон: `radial-gradient(120% 140% at 88% 112%, #27b9f5 0%, transparent 46%), linear-gradient(118deg, #03219a 0%, #0a3fca 45%, #0057d5 100%)`, `background-attachment: fixed`; базовый цвет body `#0446c8`.
- Текст: `#fff`; вторичный `rgba(255,255,255,0.6)`; подписи/оверлайны `rgba(255,255,255,0.5–0.55)`.
- Акцент (прогресс-бары, пилюли «пора повторить»): `#27b9f5`.
- Белая пилюля-CTA: фон `#fff`, текст `#0047c4`, тень `0 12px 30px rgba(2,20,90,0.35)`.
- Тёмный круглый CTA («Начать», флип): `#041e7e`, тень `0 18px 44px rgba(2,14,70,0.45)`.
- Семантика: успех `#54e6a1`/`#7defbc`, предупреждение `#ffb35c`, опасность `#ff8b8b`/`#ffa1a1` на `rgba(255,110,110,0.14)`.
- Сложность фразы: ≤3 `#54e6a1`, ≤5 `#c9e35e`, ≤7 `#ffb35c`, иначе `#ff8b8b`.

### Стекло (панели)
`background: rgba(255,255,255,0.08); border: 1px solid rgba(255,255,255,0.18); backdrop-filter: blur(12px); border-radius: 20–22px`. Hover у стеклянных кнопок: `rgba(255,255,255,0.16)`.

### Типографика
- Шрифт: **Onest** (Google Fonts), веса 400–800; фолбэк `system-ui, sans-serif`.
- Гигантские заголовки разделов: `clamp(36px, 5vw, 68px)`, вес 600, `letter-spacing: -0.03em`, строчными, с точкой `rgba(255,255,255,0.45)`.
- Hero «Сегодня» и слово на карточке: до `clamp(46px, 9vw, 150px)`.
- Оверлайны: 11px, `letter-spacing: 0.25–0.35em`, uppercase, вес 600.

### Форма
- Все кнопки/инпуты/селекты — пилюли `border-radius: 999px`, мин. высота 40–56px.
- Анимация смены экрана: `fadeUp` (18px вверх, 0.4s `cubic-bezier(0.2,0.8,0.2,1)`).
- Верно/неверно на карточке: `ringGood` (расходящееся кольцо) / `shakeBad` (тряска).
