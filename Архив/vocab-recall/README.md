# Vocab Recall — тренажёр английских фраз

Личный аналог Quizlet/Anki: ты вносишь только те слова и фразы, которые хочешь выучить, а
приложение само решает, когда их снова показать — по алгоритму интервального повторения (SM-2),
такому же, на котором строится Anki.

## Стек

- Backend: Python + Flask + SQLite (файл `server/vocab.db`, создаётся автоматически)
- Frontend: обычные HTML/CSS/JS без сборки, раздаются тем же Flask-сервером

## Вход и пароль

Приложение закрыто одним общим паролем (это личный инструмент на одного человека, без
регистрации и профилей):

- Задать свой пароль — переменная окружения `APP_PASSWORD` (например, в `server/.env` локально
  или в Environment на Render).
- Если её нет — при первом запуске пароль генерируется автоматически, сохраняется в
  `server/password.txt` и печатается в консоль сервера один раз при старте.

## Как это работает

- **Уроки** — группы карточек (например, «Сериал S01E01», «Deep Work, глава 3»). Внутри урока
  добавляешь карточки: фраза/слово на английском + перевод + необязательная заметка. Карточку
  можно отредактировать (✎) без потери накопленного прогресса повторения.
- **«Учить этот урок»** — прогоняет все карточки урока подряд, независимо от расписания. Удобно
  сразу после добавления нового урока.
- **«Повторить / учить»** на главной — собирает из *всех* уроков карточки, у которых подошёл срок
  повторения, плюс немного новых (см. лимит ниже), перемешивает и показывает по одной. Это и есть
  тот самый рандомный режим: ты не выбираешь, что учить — система сама решает.
- **Лимит новых карточек в день** (настройка на главной, по умолчанию 15) — если разом добавить
  большой урок, в очередь на сегодня попадёт только ограниченное число новых карточек, а не все
  сразу. Остальные подключатся в последующие дни. При выборе «Учить этот урок» лимит не действует
  — можно пройти весь урок целиком в любой момент.
- **Экран изучения** — направление (с английского на перевод или наоборот) выбирается случайно
  для каждой карточки. Ответ нужно **напечатать**, а не просто вспомнить и открыть: так работает
  память лучше, чем при узнавании. Кнопка **«Подсказка»** открывает следующую букву правильного
  ответа при каждом нажатии — от первой до последней, если совсем забыл. После «Проверить»
  показывается правильный ответ и авто-сверка (✓/✗) — но финальную оценку **Не помню / Трудно /
  Помню / Легко** всегда ставишь сам, даже если сверка не совпала дословно (например, у фразы
  несколько вариантов перевода).
- Если оценил «Не помню» — карточка тут же возвращается в конец текущей сессии (закрепить сразу),
  а следующий показ по расписанию будет через 1 день. Если вспомнил — интервал до следующего
  повторения растёт по формуле SM-2, тем быстрее, чем увереннее ответ.
- **Резервная копия** — кнопка «Скачать копию (.json)» на главной выгружает все уроки, карточки
  и их прогресс повторения одним файлом. «Загрузить из файла» — восстанавливает из такого файла
  (создаёт уроки заново, прогресс повторения сохраняется; повторный импорт того же файла создаст
  дубликаты, так что это скорее аварийное восстановление, а не синхронизация).

## Запуск локально

```bash
cd vocab-recall/server
python3 -m pip install -r requirements.txt
python3 app.py
```

Открыть http://localhost:5052 — при первом запуске пароль будет напечатан в консоли.

## Дальнейшие шаги (не реализовано в этой версии)

- **Автоперевод при добавлении карточки** — сейчас перевод вводится вручную. Следующий шаг —
  дергать переводческий API (например, LibreTranslate/MyMemory) и предлагать 2-3 варианта на
  выбор вместо того, чтобы вписывать перевод самому.
- **Озвучка (TTS)** — вместо видео с актёром (для этого нет легального бесплатного API,
  который ищет точную фразу в фильмах) — произношение фразы через text-to-speech при показе
  карточки.
- Деплой на Render — по такому же принципу, как остальные проекты в этом репозитории
  (см. корневой `README.md`): понадобится создать отдельный `render.yaml`-сервис с постоянным
  диском под `vocab.db`, `secret.key` и `password.txt`, и задать `APP_PASSWORD` в Environment.

## Данные и секреты

- `server/vocab.db` — вся база: уроки, карточки, история интервалов повторения.
- `server/secret.key` — секрет для подписи сессионной куки, создаётся автоматически.
- `server/password.txt` — пароль для входа, создаётся автоматически, если не задан `APP_PASSWORD`.

Все три файла создаются при первом запуске и не должны попадать в git (уже добавлены в
`.gitignore`).
